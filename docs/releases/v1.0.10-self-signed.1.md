## 🇺🇸 English Release Notes

### 🌟 What's New in v1.0.10

FinalSub v1.0.10 introduces major privacy, performance, and workflow upgrades—headlined by our zero-prompt encrypted key vault, worker-isolated parallel local TTS, enhanced subtitle alignment, and a Universal macOS distribution package.

| 😭 Before | 😎 After (v1.0.10 Upgrade) |
| :--- | :--- |
| **Keychain Prompts Interruption:** Continuous macOS system dialogs requesting access to saved API keys. | **Zero-Prompt Security:** App-private XChaCha20-Poly1305 encrypted vault. Silent, ultra-secure, zero OS prompts. |
| **Single-Threaded TTS Freezes:** Long TTS voiceover generation freezes the user interface. | **Worker-Isolated Parallel TTS:** Multi-core parallel TTS rendering isolated in dedicated worker processes. |
| **Redundant ASR Processing:** Forced to re-run speech recognition even if you already have subtitle files. | **Skip ASR & Subtitle Pairing:** Direct import for existing SRT/VTT files to jump straight to AI translation & TTS dubbing. |
| **Subtitle Line Drift:** Parakeet speech recognition occasionally shifting phrase boundaries on long audio. | **Pinpoint Alignment:** Preserved Parakeet word boundaries & refined auto-ducking dubbing timelines. |

---

### 🔥 Key Features & Improvements

#### 1. 🛡️ Vault-Grade Privacy (Zero OS Prompts)
- Replaced macOS system keychain popups with an owner-only, app-private **XChaCha20-Poly1305 encrypted credential vault**.
- Credentials for optional cloud LLMs and TTS engines are encrypted locally on disk and never exposed in UI state or logs.

#### 2. ⚡ Multi-Core Local TTS & Worker Isolation
- **Parallel Local Audio Rendering:** Configurable multi-worker concurrency for local TTS engines (Kokoro, VITS, etc.).
- **UI Responsiveness:** TTS synthesis is moved out of the main thread into an isolated worker process—keep working while dubbing renders in the background.

#### 3. 🎯 Skip ASR & Alignment Precision
- **Subtitle Pairing:** Already have a `.srt` or `.vtt` file? Pair it directly with raw video/audio and skip time-consuming ASR extraction entirely.
- **Parakeet Word Boundary Precision:** Enhanced alignment for Parakeet ASR models, preserving natural phrase boundaries and preventing line drift.
- **Dubbing Timeline Alignment:** Refined auto-ducking algorithms and voice duration matching for tight audio-visual sync.

#### 4. 🍏 Universal macOS Distribution
- Pre-compiled macOS Universal DMG supporting both Apple Silicon (M1/M2/M3/M4) and Intel Macs.
- Pinned binary checksums (`shasum -a 256`) for 100% tamper-proof download verification.

### 🍏 macOS Installation Tip (Gatekeeper)

1. **Download & Verify:**
   Download `FinalSub-1.0.10-macos-universal-self-signed.dmg` and its `.sha256` checksum file.
   ```bash
   shasum -a 256 -c FinalSub-1.0.10-macos-universal-self-signed.dmg.sha256
   # Verification output: OK
   ```

2. **Install:**
   Open the DMG and drag `FinalSub.app` to your **Applications** folder.

3. **First-Launch Approval:**
   If macOS shows a Gatekeeper warning on first launch, click **Cancel**, then go to **System Settings ➔ Privacy & Security**, scroll down to **Security**, and click **"Open Anyway"**.

### 🔥 4 大杀手级体验升级

#### 1. 🛡️ 零弹窗隐私加密 Vault (macOS 专属优化)
- 放弃了体验繁琐的系统 Keychain 授权弹窗，全面采用独立所有者权限的 **XChaCha20-Poly1305 加密安全库**。
- 所有 API Key 与敏感凭据均在本地高强度加密落盘，前端界面与日志零明文泄露，真正实现“默默守护，零打扰”。

#### 2. ⚡ 多核并发与 Worker 隔离的本地 AI 配音 (TTS)
- **本地多核并发：** Kokoro / VITS 等本地语音合成引擎支持多并发渲染，配音生成速度呈倍数提升。
- **界面彻底解耦：** 将重量级音频合成任务下沉至后台 Worker 进程，即使在生成数千句配音时，前端时间轴拖拽与字幕预览依然无比丝滑。

#### 3. 🎯 导入已有字幕跳过 ASR & 时间轴精细化对齐
- **一键挂载外部字幕：** 彻底打破“必须先识别才能翻译配音”的限制！你可以直接导入外部 SRT/VTT 字幕，立刻启动智能化双语翻译与语音配音。
- **Parakeet 识别断句对齐：** 优化 Parakeet 引擎的词界（Word Boundaries）保留逻辑，避免长语音转录时的文字错位与断句漂移。
- **精细化配音压音（Auto-Ducking）：** 优化 AI 配音与原视频背景音轨的音量压制算法，实现广播级自然混音体验。

#### 4. 🍏 Universal macOS 通用安装包
- 提供原生支持 Apple Silicon (M1/M2/M3/M4) 与 Intel 架构的 Universal 格式 DMG 安装包。
- 附带 SHA-256 完整校验机制，防篡改、安全可控。

# FinalSub 1.0.10 · macOS Universal Self-Signed

## 中文

FinalSub 1.0.10 提供从转录、翻译、校对、配音到视频合成的一体化字幕工作流，并支持本地模型原地复用、可恢复任务、字幕样式预设和独立 TTS worker。

本次分发为 macOS 12+ Universal 自签名版，同时支持 Apple Silicon 与 Intel。安装包使用 FinalSub 固定证书签名并通过深度签名、双架构、内置 FFmpeg/Whisper、最低系统版本和 DMG 完整性验证，但尚未使用 Apple Developer ID，也未经过 Apple notarization。这个下载版本首次启动时，需要按随包说明在 macOS“隐私与安全性”中手动确认；以后下载的新版本仍可能再次要求确认。

- 下载：`FinalSub-1.0.10-macos-universal-self-signed.dmg`
- 校验：下载同名 `.sha256` 并执行 `shasum -a 256 -c FinalSub-1.0.10-macos-universal-self-signed.dmg.sha256`
- 更新：当前为 GitHub Releases 手动下载，不启用应用内静默安装
- 安装说明：`INSTALL-macOS-self-signed.md`

## English

FinalSub 1.0.10 provides an integrated subtitle workflow spanning transcription, translation, proofreading, dubbing, and final video composition, with in-place local model reuse, resumable tasks, reusable subtitle styles, and isolated local TTS workers.

This download is a macOS 12+ Universal self-signed build for both Apple Silicon and Intel. It is signed with FinalSub's pinned certificate and passes deep-signature, dual-architecture, bundled FFmpeg/Whisper, deployment-target, and DMG integrity checks. It is not signed with an Apple Developer ID and is not notarized by Apple, so the first launch of this downloaded build requires the manual approval described in the included guide. A later downloaded build may require approval again.

- Download: `FinalSub-1.0.10-macos-universal-self-signed.dmg`
- Verify: download the matching `.sha256` and run `shasum -a 256 -c FinalSub-1.0.10-macos-universal-self-signed.dmg.sha256`
- Updates: manual download from GitHub Releases; silent in-app installation is disabled
- Install guide: `INSTALL-macOS-self-signed.md`

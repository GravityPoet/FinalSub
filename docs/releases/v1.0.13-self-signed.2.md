# FinalSub 1.0.13 · macOS Universal Self-Signed · Revision 2

## English

This revision improves the first-run subtitle workflow and keeps bilingual Bilibili output on the SRT path.

### A clearer first task

- The New Task workspace now follows three visible steps: choose a deliverable, add a source, and confirm the output.
- Goal selection uses direct cards for **Generate and translate**, **Generate subtitles**, and **Translate existing subtitles**.
- The source area accepts audio, video, and existing subtitle files with shorter copy and reversible selection.
- Output options stay collapsed until needed, while the summary and primary action remain visible at the right size.
- The task overview moves to wide desktop windows so smaller windows keep enough room for source selection.

### Bilibili-safe bilingual subtitles

- Bilingual tasks now default to SRT instead of forcing ASS.
- Physical line breaks are preserved in SRT output, including the source-first and translation-first orders.
- The proofreading page's primary export action now produces SRT for bilingual subtitles; ASS remains available as a general format option.

### More recoverable work

- Existing subtitle pairing, embedded subtitle extraction, and reversible source replacement remain available without deleting the original files.
- The queue keeps review gates, pipeline stages, logs, output artifacts, and retry controls visible together.
- Queue loading failures now show an actionable error state with a retry action instead of looking like an empty queue.
- The quick-start instructions now match the current “choose a deliverable → start processing” flow.

### Platform and runtime notes

- This is a macOS 12+ Universal self-signed build for `arm64` and `x86_64`.
- The pinned self-signed identity, Bundle ID, canonical `/Applications/FinalSub.app` path, and macOS 12 minimum remain unchanged.
- The package is not Apple-notarized. macOS may require first-launch approval from **System Settings → Privacy & Security → Open Anyway**.

Download the DMG and matching `.sha256` file. The Release also includes the signed updater archive, signature, `latest.json`, and the macOS installation guide.

## 中文

本修订版优化首次字幕任务流程，并将双语 B 站输出稳定在 SRT 路径。

### 更清晰的新建任务

- 新建任务页现在明确分为三步：选择交付目标、添加素材、确认输出。
- 处理目标改为直接卡片：**生成并翻译**、**仅生成字幕**、**仅翻译已有字幕**。
- 素材区支持音频、视频和已有字幕，文案更短，素材选择可以撤销或替换。
- 配音、成片和格式等低频选项默认收起，同时保留清晰的摘要和主操作入口。
- 只有宽桌面窗口显示右侧任务概览，较窄窗口会为素材选择保留足够空间。

### B 站双语字幕

- 双语任务默认使用 SRT，不再强制切换为 ASS。
- SRT 会保留真实换行，支持原文在上和译文在上两种顺序。
- 校对页双语字幕的一键导出默认生成 SRT；ASS 仍作为通用格式保留在格式菜单中。

### 更容易恢复的任务流程

- 已有字幕配对、内嵌字幕提取、素材替换和撤销继续保留，原文件不会被删除。
- 任务队列集中展示审核门槛、流水线阶段、日志、字幕产物和重试操作。
- 任务列表加载失败时会显示明确错误和重新加载按钮，不再误显示为空队列。
- 快速上手文档已同步当前“选择交付目标 → 开始处理”的实际流程。

### 平台与运行说明

- 这是 macOS 12+ Universal 自签名版本，支持 `arm64` 和 `x86_64`。
- 固定自签名身份、Bundle ID、`/Applications/FinalSub.app` 正式安装路径和 macOS 12 最低版本保持不变。
- 本包未经过 Apple 公证；macOS 首次启动时可能仍需在 **系统设置 → 隐私与安全性 → 仍要打开** 中确认。

请同时下载 DMG 和对应的 `.sha256` 校验文件。Release 还包含签名更新包、签名文件、`latest.json` 和 macOS 安装说明。

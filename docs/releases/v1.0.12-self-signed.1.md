# FinalSub 1.0.12 · macOS Universal Self-Signed

## English

FinalSub 1.0.12 enables signed in-app updates for the self-signed macOS channel.

- FinalSub now checks for new releases on startup by default and can install them directly from the app.
- Update archives are verified before installation, then FinalSub replaces the app and restarts.
- Active subtitle, model, dubbing, and video export work prevents an update restart until the operation finishes.
- The pinned self-signed identity, Universal architecture, bundle ID, and macOS 12 minimum remain unchanged.

Versions 1.0.11 and earlier need this one manual bridge installation. Future releases can be installed with **Install & Restart** inside FinalSub.

Download `FinalSub-1.0.12-macos-universal-self-signed.dmg` and its `.sha256` file. This build is self-signed and not Apple-notarized, so macOS may require first-launch approval from **System Settings → Privacy & Security → Open Anyway**.

## 中文

FinalSub 1.0.12 为 macOS 自签名渠道启用应用内签名更新。

- FinalSub 现在默认在启动时检查新版本，并可直接在应用内安装。
- 更新包会在安装前完成签名验证，随后自动替换应用并重启。
- 字幕任务、模型下载、配音或视频导出进行中时不会强制重启，待操作结束后再更新。
- 固定自签名身份、Universal 双架构、Bundle ID 与 macOS 12 最低版本保持不变。

1.0.11 及更早版本需要最后一次手动安装本桥接版。以后可直接在 FinalSub 内点击 **安装并重启** 完成更新。

请下载 `FinalSub-1.0.12-macos-universal-self-signed.dmg` 及对应 `.sha256` 文件。该版本为自签名且未经过 Apple 公证，macOS 首次启动时仍可能要求在 **系统设置 → 隐私与安全性 → 仍要打开** 中确认。

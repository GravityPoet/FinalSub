# FinalSub 1.0.13 · macOS Universal Self-Signed

## English

FinalSub 1.0.13 fixes the macOS self-signed update bridge installation path.

- Installing from a downloaded DMG or staged updater archive no longer treats the source `.app` as a second installed copy.
- LaunchServices, Spotlight, and physical-app uniqueness checks now ignore only the exact external source bundle while preserving the single canonical install at `/Applications/FinalSub.app`.
- The pinned self-signed identity, signed in-app updater, Universal architecture, bundle ID, and macOS 12 minimum remain unchanged.

This is a macOS 12+ Universal self-signed build and is not Apple-notarized. macOS may require first-launch approval from **System Settings → Privacy & Security → Open Anyway**.

Download `FinalSub-1.0.13-macos-universal-self-signed.dmg` and its matching `.sha256` file. The included `latest.json`, signed updater archive, signature, and installation guide are provided with the GitHub Release.

## 中文

FinalSub 1.0.13 修复 macOS 自签名更新桥接安装路径。

- 从下载的 DMG 或暂存更新包安装时，不再把源 `.app` 误判为第二个已安装副本。

这是 macOS 12+ Universal 自签名版本，未经过 Apple 公证；macOS 首次启动时可能仍需在 **系统设置 → 隐私与安全性 → 仍要打开** 中确认。

请下载 `FinalSub-1.0.13-macos-universal-self-signed.dmg` 及对应 `.sha256` 文件。GitHub Release 同时提供 `latest.json`、签名更新包、签名文件和安装说明。

# FinalSub v1.0.11-self-signed.1

## English release notes

FinalSub 1.0.11 continues the local-first subtitle workflow with:

- a shorter new-task path with secondary controls progressively disclosed;
- more reliable Parakeet subtitle segmentation and word-boundary handling;
- improved keyboard/focus semantics and support for `.lrc`, `.ssa`, and `.ass` subtitle formats;
- deterministic macOS sidecar preparation, pinned FFmpeg inputs, and an Intel runtime validation job;
- browser-development fixtures for subtitle directory scanning and read/write flows.

This file is the source release note for the self-signed package workflow. It does not mean that a GitHub Release, notarized package, or production updater has been published.

## 中文发布说明

FinalSub 1.0.11 延续本地优先的字幕工作流，重点更新：

- 缩短新任务主路径，低频选项改为渐进披露；
- 修复 Parakeet 字幕分段与词界保留问题；
- 改善键盘与焦点语义，并补齐 `.lrc`、`.ssa`、`.ass` 字幕格式支持；
- 固化 macOS sidecar 准备流程、FFmpeg 输入与 Intel 运行时验收任务；
- 为浏览器开发环境补充字幕目录扫描和读写 fixture，避免误报 Tauri 文件 API 错误。

本文件是自签名包流程使用的发布说明源文件；它不表示 GitHub Release、Notarization 或正式应用内更新已经发布。

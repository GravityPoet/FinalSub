# FinalSub 1.0.11 · macOS Universal Self-Signed

## English release notes

FinalSub 1.0.11 continues the local-first subtitle workflow with:

- a shorter new-task path with secondary controls progressively disclosed;
- more reliable Parakeet subtitle segmentation and word-boundary handling;
- improved keyboard/focus semantics and support for `.lrc`, `.ssa`, and `.ass` subtitle formats;
- native Apple silicon execution with Universal main, FFmpeg, and Whisper binaries, so normal launch does not depend on Rosetta;
- deterministic macOS sidecar preparation, refreshed pinned FFmpeg inputs, and a real Intel runtime validation job;
- smaller production startup chunks and reliable browser-development subtitle directory/read/write flows.

This is a macOS 12+ Universal self-signed build. It is not notarized with an Apple Developer ID, so each newly downloaded version may require the first-launch approval described in the included guide.

- Download: `FinalSub-1.0.11-macos-universal-self-signed.dmg`
- Verify: download the matching `.sha256` file and run `shasum -a 256 -c FinalSub-1.0.11-macos-universal-self-signed.dmg.sha256`
- Install guide: `INSTALL-macOS-self-signed.md`
- Updates: manual download from GitHub Releases; silent in-app installation is disabled

## 中文发布说明

FinalSub 1.0.11 延续本地优先的字幕工作流，重点更新：

- 缩短新任务主路径，低频选项改为渐进披露；
- 修复 Parakeet 字幕分段与词界保留问题；
- 改善键盘与焦点语义，并补齐 `.lrc`、`.ssa`、`.ass` 字幕格式支持；
- Apple Silicon 强制原生运行，主程序、FFmpeg 与 Whisper 均为 Universal，正常启动不依赖 Rosetta；
- 固化 macOS sidecar 准备流程、更新固定 FFmpeg 输入，并增加真 Intel 运行时验收；
- 缩小生产启动代码块，并补齐浏览器环境的字幕目录扫描和读写流程。

本次提供 macOS 12+ Universal 自签名版，尚未使用 Apple Developer ID 公证；每次新下载版本首次打开时，可能仍需按随包说明在 macOS“隐私与安全性”中确认。

- 下载：`FinalSub-1.0.11-macos-universal-self-signed.dmg`
- 校验：同时下载 `.sha256`，运行 `shasum -a 256 -c FinalSub-1.0.11-macos-universal-self-signed.dmg.sha256`
- 安装说明：`INSTALL-macOS-self-signed.md`
- 更新方式：从 GitHub Releases 手动下载，不启用应用内静默安装
